# 🚀 Portfólio | Lucas Fernandes

Portfólio pessoal responsivo desenvolvido com HTML, CSS e JavaScript.

Este repositório reúne minha trajetória profissional, projetos de software, competências técnicas, certificações e canais de contato.

## ✨ Visão geral

- Interface responsiva para desktop, tablet e celular.
- Projetos com imagens ampliáveis em modal.
- Contato direto por WhatsApp, e-mail, LinkedIn e GitHub.
- Experiência estática, rápida e sem dependências de build.

## 💻 Executar localmente

Abra o arquivo `index.html` no navegador ou use uma extensão como Live Server no VS Code.
